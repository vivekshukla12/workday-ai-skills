# Contributing

Contributions that add or improve reusable Workday-related AI skills are welcome.

## Structure

Place each skill in its own directory under `skills/`. A skill must include a valid `SKILL.md`; include only supporting files that the skill actually needs.

## Public-repository guardrails

By submitting a contribution, you confirm that it contains no credentials, confidential information, tenant metadata, customer or project information, personal or production data, real Workday identifiers, real tenant queries or responses, proprietary attachments, or other restricted material.

Use synthetic examples and obvious placeholders. Do not upload Workday manuals or reproduce substantial documentation text. Prefer concise original explanations with links to publicly available authoritative sources.

Before publishing, follow every requirement in [AGENTS.md](AGENTS.md), review the complete diff, and scan all new Git history. If you are uncertain whether something is safe to publish, exclude it until the repository owner has reviewed it.
