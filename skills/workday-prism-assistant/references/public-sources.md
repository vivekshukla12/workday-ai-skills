## Source-use policy

Use these pages to verify current product behavior, syntax, function availability, security behavior, limits, and version-sensitive capabilities.

When updating this skill:

- Write original explanations and synthetic examples.
- Link to Workday for authoritative detail.
- Do not copy entire Workday tables, screenshots, manuals, course PDFs, or substantial passages.
- Do not use customer-only Workday Community content as repository material unless it is independently rewritten from information that is also publicly available and publication is otherwise permitted.

## Version-sensitive topics

Recheck official Workday documentation before giving definitive answers about:

- Numeric data/file/upload limits.
- REST API versions and resource paths.
- Supported connection types.
- Newly added or retired expression functions.
- Security-domain names or supported constrained-security patterns.
- Feature availability that can vary by Workday release or tenant configuration.

If the agent cannot verify a version-sensitive fact, label it as requiring confirmation instead of guessing.
